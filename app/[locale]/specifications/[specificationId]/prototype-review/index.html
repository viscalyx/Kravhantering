What each option changes

OptionStructureWhat to judge
A · Compact stackSmaller pill tabs and actions; package filters keep a separate band.Maximum height gain with the smallest rearrangement. Check tab labels with expanded navigation.
B · Full-width tabsTabs get their own line; filters and actions share the line below.Recommended starting point: clearer labels, only 3px less list space than A in this fixture.
C · Shared shelfBoth tab groups sit above the panels; each panel combines filters and actions.Does the separation help orientation? Less height gain and more filter wrapping in narrow panels.

All options keep text size and row content, reduce the footer from 85px to 41px, reduce the bottom gap from 40px to 8px, and preserve independent panel scrolling. No winner has been approved or promoted to production.

Five-minute live review

  1. Open the live variant. Sign in with the local demo account ada.admin / devpass. Both panels open automatically.
  2. Use 0 / A / B / C in the floating bar, or left/right arrows. Press H to hide/restore the bar. Inspect shows live geometry and state.
  3. At 1440 × 900, flip 0 → B. Watch the first row move up and the last visible row move down. The copyright stays visible without page overflow.
  4. Expand navigation, switch to dark theme, scroll each list, and try tabs, filters and column controls. Drag the panel divider; also focus it and use arrow keys.
  5. Compare the 1920 × 1080 capture, then pick A, B, C, or a combination. Saving application data is intentionally blocked. Reload resets preview preferences; the variant stays in the URL.

Evidence: 32 browser captures cover four layouts, two resolutions, two navigation states, and two themes. Independent scrolling and sticky headers were exercised wherever lists overflowed. These are prototype checks, not the full production acceptance suite. Multi-package filtering, other tabs, and narrower viewports have separate notes in the full guide.
