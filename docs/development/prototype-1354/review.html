A · Compact table

Closest to the issue brief. Narrow prefix, stronger name, wrapping description, aligned responsibility and compact actions.

Tradeoff: long descriptions and many co-authors still make a row tall. Small screens use internal table scrolling.

B · Description rows

Prefix, name and actions lead each row. The description spans the reading area; owner and co-authors sit below it.

Tradeoff: easier reading of long text, but fewer areas visible and weaker comparison down columns.

C · Area cards

Each area groups its name, full description and responsibility. Two columns on desktop; one on narrow screens.

Tradeoff: natural grouping, but variable card heights leave gaps. This explores a departure from the requested table structure.
