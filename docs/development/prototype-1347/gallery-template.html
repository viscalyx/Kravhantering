What this settles

All three designs remove default header clipping in the captured desktop matrix and give more space to requirement text. A uses the least height; B creates a clearer label/control hierarchy; C makes filter labels explicit. Choosing a winner, or combining ideas, remains a design decision.

Manual widths, custom columns and narrow screens may still require horizontal scrolling. Column preferences are deliberately temporary in this prototype. Production implementation must preserve saved preferences and receive normal regression and accessibility testing.
