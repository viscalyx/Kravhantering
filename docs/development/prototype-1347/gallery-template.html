What this settles

Revised A follows the maintainer’s preferred widths, shortens the status label to Status and uses single-line ellipsis when narrowed. The live width panel supports further adjustments. B/C retain the earlier wrapping alternatives. The maintainer selects revised A as the implementation reference for issue #1347. Production implementation remains a separate step.

A’s wider defaults require horizontal scrolling at 1440 px; custom columns and narrower screens may also need it. Column preferences are deliberately temporary in this prototype. Production implementation must preserve saved preferences and receive normal regression and accessibility testing.
