Throwaway logic prototype

Author one database operation. Inspect every projection.

This prototype models the required database jobs as one guide contract step. The step contains ordered commands with stable identities. A pure, deterministic compiler projects the step for one deployment scenario.

Question under test: Is a fixed, typed guide contract step expressive enough for first installation and planned-downtime upgrade across single-node, app-node-tls, and app-node-http, while still rejecting a general-purpose condition or shell language?
