# Application-wide visual restyling from issue 1346

The application-wide visual restyling proposal in issue #1346 is retained as
an exploratory prototype. Production implementation under that issue is not
planned.

## Decision

The maintainer chooses to preserve the throwaway prototype and its review
evidence on `prototype/issue-1346`, and close the implementation request as
not planned. The prototype is a reference for the explored appearance; its
existence does not mean that the production application implements the change.

This record concerns the specific application-wide proposal in #1346. It does
not reject individual UI improvements or the separately tracked layout issues.
No broader technical or product-policy reason is asserted for the closure.

## Preserved prototype

The prototype compares the branch baseline with the proposed styling on the
existing application routes. It includes a live Before/Proposed switcher,
a change and verification checklist, and an offline screenshot gallery.

See the [prototype guide](../docs/development/prototype-1346/README.md) for
launch instructions, the full change list, verification steps and limitations.
