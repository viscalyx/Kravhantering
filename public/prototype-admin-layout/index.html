What this does and does not decide

A stays closest to the issue’s proposed compact rows. B favors tabular scanning and bottom actions. C gives the row list more vertical room and makes the settings summary prominent, at the cost of horizontal space. No option has been selected for production.

The desktop capture matrix covers Swedish, two sizes, two navigation states, both themes and all four layouts. Additional captures cover English, long text and 320-pixel mobile layouts for A/B/C. Functional checks exercise local editing and keyboard controls; this is not a production accessibility audit or the full application test suite.
